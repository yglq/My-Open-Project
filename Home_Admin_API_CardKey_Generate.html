批量生成卡密
请求接口
POSTURL + /API/cardkey/generate.php
请求参数
参数名类型必填说明
ConfigIdString是数据库 ID
TokeyString是数据库密钥
CountInt否生成数量，默认 10，最大 100
TypeInt是卡密类型：1金币 2会员 3变量 4JSON
GoldIntType=1 时必填金币数量
VipDaysIntType=2 时必填会员天数
ValueListJSONType=3 时必填自定义变量奖励，如 [{"name":"score","value":5}]
JsonListJSONType=4 时必填自定义JSON奖励，选择一个变量设置值，如 [{"table":"test2","col":"test2_s","value":"fh"}]
响应
成功 (code=0)
{"code":0,"message":"已生成 10 张卡密","count":10,"cards":["A1B2C3D4E5F6",...]}
失败 (code=1)
{"code":1,"message":"Tokey 验证失败"}
提示
• 使用后台 Tokey 鉴权（ConfigId + Tokey）
• 卡密为 12 位大写随机串，全局唯一
• ValueList / JsonList 需为合法 JSON 字符串
