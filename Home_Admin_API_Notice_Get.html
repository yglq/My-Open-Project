获取公告
请求接口
POST GET {服务器地址}/API/notice/notice_get.php
请求参数
参数名类型必填说明
ConfigId String 是 数据库 ID
ApiToken String 是 API 密钥（未开启 Token 验证时可不填）
响应
成功响应 (code=0)
{ "code": 0, "content": "这是公告内容" }
失败响应 (code=1)
{ "code": 1, "message": "公告未开启" }
示例
GET 请求
URL + /API/notice/notice_get.php?ConfigId=你的ConfigId&ApiToken=你的ApiToken
POST 请求
URL + /API/notice/notice_get.php 参数：ConfigId=你的ConfigId&ApiToken=你的ApiToken
💡 替换示例中的参数为实际值即可测试
提示
• 接口支持 GET 和 POST 两种请求方式
• 只有当后台配置中"公告开关"(notice_switch) 开启时才能获取到公告
• 如果后台开启了 Token 验证(api_token_switch=1)，必须传入正确的 ApiToken
• 如果未开启 Token 验证，ApiToken 参数可以传任意值
