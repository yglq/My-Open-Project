删除未使用卡密
请求接口
POSTURL + /API/cardkey/delete.php
请求参数
参数名类型必填说明
ConfigIdString是数据库 ID
TokeyString是数据库密钥
CardIdInt是要删除的卡密记录 id（来自列表接口）
响应
成功 (code=0)
{"code":0,"message":"删除成功"}
失败 (code=1)
{"code":1,"message":"卡密不存在或已使用，无法删除"}
提示
• 使用后台 Tokey 鉴权
• 仅能删除未兑换的卡密（used_at 为 null），已兑换记录不可删除
• CardId 通过「卡密列表」接口获取
