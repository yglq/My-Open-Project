获取自定义JSON表
请求接口
POSTGETURL + /API/user/get_custom_table.php
请求参数
参数名类型必填说明
ConfigIdString是数据库 ID
ApiTokenString是API 密钥
UsernameString是子用户账号
PasswordString是子用户密码
TableNameString是JSON表名（后台"自定义JSON表"里定义的）
返回示例
{ "code": 0, "data": [ {"等级": 3, "道具": "铁剑"}, {"等级": 5, "道具": "药水"} ], "count": 2 }
• TableName 必须在后台"自定义JSON表"中已定义
• 返回该子用户的整表行数组（按写入顺序）
• 写入用 update_custom_table.php（replace 整表 / append 追加行）
• get_var.php 里直接传表名也可以读同一份数据
