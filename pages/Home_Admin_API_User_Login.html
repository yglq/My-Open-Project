子用户登录
请求接口
POSTURL + /API/user/login.php
请求参数
参数名类型必填说明
ConfigIdString是数据库 ID
ApiTokenString是API 密钥
UsernameString是账号
PasswordString是密码
响应
成功 (code=0)
{"code":0,"message":"登录成功","user_id":1,"username":"xxx","nickname":"xxx","avatar":"xxx.png"}
失败 (code=1)
{"code":1,"message":"账号或密码错误"}
提示
• 受后台"登录开关"控制
• 封号期间无法登录
示例
POST 请求
URL + /API/user/login.php 参数：ConfigId=xxx&ApiToken=xxx&Username=xxx&Password=xxx
💡 替换示例中的参数为实际值即可测试
