修改密码
请求接口
POSTURL + /API/user/update_password.php
请求参数
参数名类型必填说明
ConfigIdString是数据库 ID
ApiTokenString是API 密钥
UsernameString是账号
OldPasswordString是原密码
NewPasswordString是新密码
响应
成功 (code=0)
{"code":0,"message":"密码修改成功"}
失败 (code=1)
{"code":1,"message":"该账号不允许修改密码"}
提示
• 受密码长度限制
• 受子用户"可修改密码"设置控制
• 需要验证原密码
示例
POST 请求
URL + /API/user/update_password.php 参数：ConfigId=xxx&ApiToken=xxx&Username=xxx&OldPassword=旧密码&NewPassword=新密码
💡 替换示例中的参数为实际值即可测试
